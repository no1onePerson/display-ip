# Security

Do not post secrets or personal IP history in public issues. Use GitHub private vulnerability reporting if it is enabled for this repository; otherwise contact the repository owner privately before disclosing exploit details. No response-time guarantee is implied.

Keep TLS verification and App Transport Security enabled. Provider responses are untrusted data. API tokens belong in Keychain and signing credentials belong in GitHub secrets. Development artifacts are not notarized and must not be represented as trusted production binaries.
