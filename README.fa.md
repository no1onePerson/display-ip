# IP Prism برای macOS

![تصویر مفهومی منشور شیشه‌ای IP Prism](Documentation/images/ip-prism-hero.webp)

تصویر بالا یک طرح مفهومی است، نه تصویری از محیط واقعی برنامه.

**IP Prism** یک برنامهٔ بومی مک برای مشاهده و پایش نشانی اینترنتی عمومی شماست. برنامه در نوار منو قرار می‌گیرد و با استفاده از چند سرویس، اطلاعات موجود دربارهٔ اتصال شما را نمایش می‌دهد. برای استفادهٔ پایه به حساب کاربری یا کلید API نیاز نیست.

[English README](README.md) · [دانلود نسخه‌ها](https://github.com/no1onePerson/display-ip/releases) · [حریم خصوصی](PRIVACY.md)

> **وضعیت پروژه:** نسخهٔ فعلی پیش‌نمایش توسعه است. رابط کاربری، پنجرهٔ تنظیمات، مجوزها، تغییر VPN و اشتراک داده با ویجت هنوز باید روی مک واقعی بررسی شوند. نسخه‌های پیش‌نمایش با گواهی توسعه‌دهندهٔ اپل امضا و تأیید رسمی (notarized) نشده‌اند؛ ممکن است Gatekeeper اجرای آن‌ها را مسدود کند.

## امکانات

- نمایش IP عمومی در نوار منو و پنل شیشه‌ای با بخش‌های اتصال، موقعیت، سرویس‌دهنده‌ها و تاریخچه.
- پشتیبانی از IPv4 و بررسی جداگانهٔ IPv6؛ نمایش اطلاعات موقعیت و شبکه در صورت ارائه توسط سرویس.
- هشت سرویس: IPWho.is، IPinfo، ipapi.co، GeoJS، FreeIPAPI، ipify، icanhazip و Cloudflare Trace. اگر سرویس خودکار پاسخ ندهد، سرویس بعدی امتحان می‌شود.
- بررسی تغییرات شبکه و درخواست مجدد پس از تغییر اتصال، از جمله تغییراتی که هنگام روشن یا خاموش کردن VPN به سیستم اعلام می‌شوند. تشخیص قطعی VPN تضمین نمی‌شود.
- تاریخچهٔ محلی تغییرات تأییدشده، خروجی JSON و CSV، اعلان‌های اختیاری، ساعت سکوت و صداهای قابل تنظیم.
- ویجت‌های کوچک، متوسط و بزرگ، گزینهٔ اجرا هنگام ورود به سیستم، تنظیم ظاهر نوار منو و حالت حفظ حریم خصوصی.

داده‌های مکانی تقریبی و بر اساس IP هستند. همهٔ سرویس‌ها نام شهر، ISP یا سایر جزئیات را ارائه نمی‌کنند. وضعیت VPN یا پراکسی بدون شواهد کافی «نامشخص» نمایش داده می‌شود.

## نصب

1. به [صفحهٔ انتشارها](https://github.com/no1onePerson/display-ip/releases) بروید و پس از انتشار موفق، فایل `IPPrism.dmg` را دریافت کنید.
2. فایل را باز کنید و **IP Prism.app** را به پوشهٔ **Applications** بکشید.
3. برنامه را اجرا کنید؛ نماد آن در نوار منو ظاهر می‌شود.
4. برای افزودن ویجت از گزینهٔ **Edit Widgets** در macOS استفاده کنید.

حداقل سیستم مورد نیاز macOS 14 است. نسخهٔ پیش‌نمایش ممکن است به دلیل نداشتن امضای Developer ID و تأیید اپل توسط Gatekeeper مسدود شود. اشتراک داده با ویجت نیز به تنظیم صحیح App Group و امضای اپل نیاز دارد. برای انتشار قابل اعتماد، مراحل [امضا و انتشار](Documentation/RELEASE.md) را دنبال کنید.

## تنظیمات و مجوزها

در تنظیمات می‌توانید سرویس ترجیحی، ترتیب سرویس‌ها، فاصلهٔ به‌روزرسانی، شکل نمایش نوار منو، اعلان‌ها و صدا را تغییر دهید. دسترسی به اعلان‌ها فقط هنگام فعال کردن آن‌ها درخواست می‌شود. اجرای خودکار از طریق تنظیمات رسمی macOS انجام می‌شود و ممکن است نیاز به تأیید در **Login Items** داشته باشد.

برای بررسی جداگانهٔ IPv6، گزینهٔ مربوط را در تنظیمات فعال کنید. در برخی شبکه‌ها IPv6 در دسترس نیست. ویجت آخرین دادهٔ ذخیره‌شده را نشان می‌دهد و زمان به‌روزرسانی آن را سیستم تعیین می‌کند؛ به‌روزرسانی لحظه‌ای تضمین نمی‌شود.

## حریم خصوصی

برنامه سرویس آمارگیری یا حساب کاربری ندارد. هر سرویس‌دهنده‌ای که با آن تماس گرفته می‌شود، IP عمومی درخواست را می‌بیند و تابع سیاست و محدودیت‌های خودش است. تاریخچه روی دستگاه نگهداری می‌شود و حالت حریم خصوصی اطلاعات حساس را در رابط کاربری، اعلان‌ها و دادهٔ اشتراکی ویجت پنهان می‌کند؛ این حالت تاریخچه را حذف نمی‌کند. خروجی‌های تاریخچه شامل نشانی‌های واقعی هستند.

[سیاست حریم خصوصی](PRIVACY.md) · [فهرست سرویس‌ها و وضعیت بررسی](Documentation/PROVIDERS.md)

## ساخت برای توسعه

برای ساخت برنامه و ویجت به مک، Xcode 16.4 یا جدیدتر و macOS 14 یا جدیدتر نیاز دارید. فایل `macOS/IPPrism.xcodeproj` را باز کنید، طرح **IPPrism** را انتخاب کنید و شناسه‌ها، تیم و App Group متعلق به حساب توسعه‌دهندهٔ خود را تنظیم کنید.

```bash
swift test --package-path macOS
xcodebuild -project macOS/IPPrism.xcodeproj -scheme IPPrism \
  -configuration Debug -derivedDataPath macOS/build CODE_SIGNING_ALLOWED=NO build
```

آزمون‌های بخش مشترک Swift روی لینوکس اجرا شده‌اند. وضعیت ساخت، محدودیت‌ها و مواردی که هنوز باید روی مک آزمایش شوند در [گزارش اعتبارسنجی](Documentation/VALIDATION.md) آمده است. بررسی فعلی مستندات و شرایط سرویس‌های خارجی به دلیل محدودیت شبکه کامل نشده است.
